# NEXUS App

Web search + weather intelligence app built with React, Vite, and Express.
Built using Bolt.new (AI app builder).

## Features
- Server-side real web search and news
- Real weather data via Open-Meteo (current, hourly, 7-day forecast)
- Browser geolocation with city-search fallback
- Weather map
- Saved search/news history
- Android app built with Capacitor
